# Chapter 2 Lab: Service Accounts, Workload Identity Federation, and Impersonation

**Estimated time:** 22 minutes

## Exercise

Configure Workload Identity Federation for a GitHub Actions workflow to authenticate to Google Cloud without a downloaded service account key, then verify via gcloud auth print-access-token using impersonation

## Key takeaway

Prefer Workload Identity Federation and impersonation-based short-lived credentials over service account keys wherever the exam presents that choice.
