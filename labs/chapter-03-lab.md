# Chapter 3 Lab: IAM Authorization: Conditions, Deny Policies, and Org Policy

**Estimated time:** 25 minutes

## Exercise

Create an IAM deny policy denying storage.objects.delete for all principals except a break-glass group, then create an IAM condition granting temporary access with an expiry timestamp, verified in Policy Simulator

## Key takeaway

Deny policies, IAM conditions, and Privileged Access Manager solve different access-restriction problems — the exam expects you to pick the right one per scenario.
