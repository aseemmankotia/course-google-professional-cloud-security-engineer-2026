# Chapter 4 Lab: Perimeter Controls: Cloud NGFW, IAP, and Cloud Armor

**Estimated time:** 20 minutes

## Exercise

Enable Identity-Aware Proxy in front of a backend service, configure the iap.httpsResourceAccessor IAM binding, and attach a Cloud Armor security policy with a rate-limiting rule to the same load balancer

## Key takeaway

IAP, Cloud NGFW, and Cloud Armor address different layers of perimeter defense — application identity, network filtering, and edge WAF protection respectively.
