# Chapter 5 Lab: VPC Service Controls, Shared VPC, and Private Connectivity

**Estimated time:** 25 minutes

## Exercise

Create a VPC Service Controls perimeter around a project containing a BigQuery dataset and Cloud Storage bucket, then attempt to access the data from an unauthorized network outside the perimeter and observe the block

## Key takeaway

VPC Service Controls stop data exfiltration at the service boundary, while Shared VPC, peering, and private connectivity options control network-level reachability.
