# Chapter 6 Lab: Sensitive Data Protection, Secret Manager, and Data Service Access Controls

**Estimated time:** 22 minutes

## Exercise

Run a Sensitive Data Protection inspection job on a Cloud Storage bucket containing sample PII, apply a de-identification template using format-preserving encryption, then store the resulting encryption key in Secret Manager with rotation enabled

## Key takeaway

Sensitive Data Protection's de-identification techniques and IAM-based access controls on BigQuery, Cloud Storage, and Cloud SQL solve distinct data-protection needs — pick based on reversibility and access-scope requirements.
