# Chapter 7 Lab: Encryption Everywhere: CMEK, Cloud EKM, and Confidential Computing

**Estimated time:** 20 minutes

## Exercise

Create a Cloud KMS key ring and key, apply it as CMEK to a new Cloud Storage bucket, then simulate a compliance-driven revocation by disabling the key version and confirming object access fails

## Key takeaway

Default encryption, CMEK, Cloud EKM, and Confidential Computing form a spectrum of control from 'Google manages everything' to 'customer controls keys and memory' — match the scenario's control requirement to the right tier.
