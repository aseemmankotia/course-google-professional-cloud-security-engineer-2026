# Chapter 8 Lab: Cloud Storage Lifecycle and Securing AI/ML Workloads

**Estimated time:** 18 minutes

## Exercise

Configure a Cloud Storage lifecycle rule to transition objects to Archive storage after 365 days and enable bucket lock retention for 7 years, then place a Vertex AI training data bucket inside a VPC Service Controls perimeter

## Key takeaway

Lifecycle rules manage cost and retention, bucket lock enforces compliance-grade immutability, and AI/ML workload security requires scoping both data access and agent grounding permissions.
