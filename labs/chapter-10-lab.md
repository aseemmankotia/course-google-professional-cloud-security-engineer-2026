# Chapter 10 Lab: Cloud Audit Logs, Cloud IDS, and Security Command Center

**Estimated time:** 20 minutes

## Exercise

Enable Data Access audit logs for BigQuery, create an aggregated log sink at the organization level exporting all Data Access logs to a centralized Cloud Storage bucket, then create a Security Command Center notification for high-severity findings

## Key takeaway

Cloud Audit Logs and VPC/NGFW logs feed visibility, while Security Command Center tiers determine which automated detection sources you actually get.
