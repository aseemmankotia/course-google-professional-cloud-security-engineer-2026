# Chapter 11 Lab: Shared Responsibility, Assured Workloads, and Compliance Scoping

**Estimated time:** 18 minutes

## Exercise

Provision an Assured Workloads folder with a specific compliance control package, verify the inherited organization policies restricting resource locations, then enable Access Approval on the parent organization and simulate a Google support access request requiring approval

## Key takeaway

Compliance on Google Cloud is a shared responsibility mapped through concrete controls — Assured Workloads, Access Approval, and organization policies — not a certification granted by any single service.
